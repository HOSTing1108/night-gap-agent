### 정류장별 하루 이용 (허브 API) 연결 방법
- 허브 API는 승차·환승만 있고 하차와 시간대가 없어요. 그래서 "밤 하차"가 아니라 **정류장의 하루 이용 규모**로 순위를 매기고, 화면과 건의서에 그렇게 적어요.
- API의 정류소 아이디(7자리)와 정류장 위치 자료의 아이디(9자리)는 체계가 달라요. 정류장 이름(띄어쓰기·괄호 제거)으로 연결하고, 안 맞으면 "/" 앞부분과 "~방면/방향"을 뗀 이름으로 한 번 더 찾아요. 이용 인원의 **92.2%**가 자동으로 연결됐어요.
- 같은 이름의 정류장(양방향 등)에는 이용 인원을 똑같이 나눠 넣어요.
- API는 한 번에 100행, 하루 1,000회까지라 날짜 하나에 약 65~80회가 들어요. `tools/fetch_hub_usage.py`가 날짜별로 저장하고 이어 받아요. 키는 `config.env`의 `JEJU_HUB_KEY`에만 두고 제출물에는 넣지 않아요.
- 실행 결과: 이용 기록이 있는 정류장 3,143곳 중 2,319곳이 CCTV 100m·비상벨 200m 밖이에요. 1위 제주대학교(하루 약 1,169명), 2위 한라병원, 3위 제주도청 신제주로터리. 1~3위는 기준을 바꿔도 모두 유지돼요.

### 실제 공개 자료로 돌린 결과
- 정류장 위치(공공데이터포털)와 제주데이터허브 정류장별 이용을 연결해 분석해요. 숫자와 상위 10곳은 `docs/result_explanation.md` 4절에 있고, `python tools/build_plan.py`로 다시 만들어요.
- 최근 90일(2025-07-29~10-26) 제주 전체 버스 승차 중 22~24시는 2.0%(하루 약 516명), 19~24시는 15.5%예요.
- 같은 이름의 양방향 정류장은 한 곳으로 셉니다. 구역 이름은 CCTV·비상벨 지번주소의 동·읍·면(법정동)으로 붙여요.

## 3. 전처리 및 분석 흐름

```
CSV 올리기
 └ profile_csv      인코딩 판별(UTF-8, CP949), 컬럼별 숫자 범위와 대표값만 요약
 └ identify_dataset 컬럼 이름 규칙으로 정류소, 이용 현황, CCTV, 비상벨, 보안등 판별
 └ load_points      좌표 컬럼 찾기 → TM 좌표면 위경도로 변환 → 제주 범위 밖 제거
                    → CCTV는 같은 좌표(약 1m)·같은 목적이면 한 곳으로 합침
 └ load_stops       정류장마다 가장 최근 base_date의 위치만 사용
 └ night_demand     밤 시간대(기본 21~23시) 하차 인원 / 일수 = 일평균, 마지막 이용 시각
 └ compute_gaps     정류장 반경 안의 CCTV(100m), 비상벨(200m), 보안등(50m) 수
                    → 공백 유형 판정 → 점수 = 수요 백분위 × 공백 가중합 (수요 자료 없으면 공백 가중합)
 └ check_robustness 기준 거리·시간대 6가지로 다시 계산 → 상위 10곳 유지 수, 정류장별 유지 횟수
 └ diagnose         수요 부족, 지역 쏠림, 보안등 자료 없음 점검
 └ export_check     10 미만 값 가리기
 └ 결과 카드, 지도, CSV
```

### 좌표 변환
- 지원 좌표계: EPSG:5174(Bessel, 7변수 변환), EPSG:5175, EPSG:5181, EPSG:5186
- 외부 라이브러리 없이 직접 구현했어요(`app/geo.py`). 왕복 오차는 1cm 미만이고 테스트로 확인해요.

### 점수 산식
- 수요 백분위: 분석 범위 정류장 중 밤 하차 일평균의 순위 (0~100)
- 공백 가중치: 눈 1.0, 벨 1.0, 빛 1.0, 막차 0.5
- 점수 = 수요 백분위 / 100 × 공백 가중치 합
- 수요가 0이거나 공백이 없으면 점수는 0이에요.

### 결과 검증 (robustness)
| 바꾸는 조건 | 값 |
|---|---|
| CCTV 기준 거리 | 50m, 150m (기본 100m) |
| 비상벨 기준 거리 | 100m, 300m (기본 200m) |
| 시간대 | 한 시간 넓히기, 한 시간 좁히기 (이용 현황이 있을 때만) |

- 조건마다 상위 10곳이 몇 곳 남는지 세고, 정류장마다 "기준 바꿔도 n/4"를 결과 카드와 건의서에 붙여요.
- 가상 데이터 기준: 상위 10곳 중 평균 7.7곳 유지, 3곳은 모든 조건에서 유지.
