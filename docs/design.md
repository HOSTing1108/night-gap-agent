# 안심하차 Agent: 설계 문서 (v0.1, 2026-11-09)

## 1. 한 줄 정의
**밤에 버스에서 내려 걸어가는 사람이 많은데, CCTV, 안전비상벨, 마지막 버스가 부족한 정류장 주변을 찾아 우선 개선 10곳을 근거와 함께 뽑는 Agent.**

- 범죄 지도나 위험 지도가 아니에요. **기반시설 공백**을 보여주는 지도예요.
- 결론은 항상 같은 형태예요. 우선 개선 10곳마다 공백 유형, 근거 숫자, 건의 문장 초안을 붙여요.

## 2. 사용자와 질문 예시
| 사용자 | 입력 예시 |
|---|---|
| 도민, 학부모 | "우리 애가 밤 10시에 노형동에서 버스 내리는데, 그 근처 괜찮아?" |
| 주민자치위원, 이장 | "우리 읍에서 CCTV나 비상벨을 먼저 놓아야 할 곳 건의서 만들어줘" |
| 공무원, 의원실 | "제주시 동지역 밤길 공백 상위 10곳과 근거 정리해줘" |

## 3. 분석 단위를 정류장으로 정한 이유
- 50m 격자 유동인구(4-07)의 격자코드는 7자리 숫자이고, 명세서에 **좌표 대응표가 없어요.** 그래서 CCTV 위치와 바로 겹칠 수 없어요. 대응표 제공 여부는 게시판에 질문해요.
- 반면 버스 정류소(3-03)는 위경도가 있고, 정류소별 시간대 이용(3-04)은 **반출 가능**해요.
- "밤에 버스에서 내린 사람"은 걸어서 귀가하는 사람이에요. 밤길이 시작되는 지점이라 설명이 직관적이에요.
- 50m 격자는 **선택 계층**이에요. 대응표가 있으면 정류장 주변 밤 유동인구로 보강하고, 없으면 읍면동 단위(4-11)로 보강해요.

## 4. 데이터
| 구분 | 데이터 | 출처 | 형식 | 반출 |
|---|---|---|---|---|
| 핵심 | 3-03 버스 정류소 정보 | 센터 | 위경도 | 가능 |
| 핵심 | 3-04 버스 정류소별 이용 현황 | 센터 | 정류소 × 시간대 × 승하차 | 가능 |
| 핵심 | 전국CCTV표준데이터(제주 필터) | 공공데이터포털 | WGS84 위경도 | 공개 |
| 핵심 | 전국안전비상벨위치표준데이터(제주 필터) | 공공데이터포털 | 위경도 또는 TM 좌표 | 공개 |
| 선택 | 보안등 위치 | 지자체 제공 시 | 위경도 | 공개 |
| 보강 | 4-07 50m 격자 유동인구 | 센터 | 격자 × 시간대 | 불가, 가공만 |
| 보강 | 4-11 읍면동 유동인구 | 센터 | 읍면동 × 시간대 | 불가, 가공만 |

## 5. 공백 지표
정류장 s마다 다음을 계산해요. 거리 기준은 설정에서 바꿀 수 있어요.

| 지표 | 정의 | 기본값 |
|---|---|---|
| 밤 하차 수요 | 21~23시 하차 인원의 일평균 | 21, 22, 23시 |
| 눈 공백 | 반경 안에 방범 목적 CCTV가 없음 | 100m |
| 벨 공백 | 반경 안에 안전비상벨이 없음 | 200m |
| 막차 공백 | 마지막으로 이용 기록이 있는 시각이 이름 | 22시 이전 |
| 빛 공백 | 반경 안에 보안등이 없음 (자료가 있을 때만) | 50m |

**우선순위 점수 = 밤 하차 수요 백분위 × (공백 수의 가중합)**
- 가중치 기본값은 눈 1.0, 벨 1.0, 막차 0.5, 빛 1.0이에요.
- 수요가 0이면 점수도 0이에요. 사람이 없는 곳은 우선순위에서 빠져요.
- 모든 계산은 결정론적 파이썬 함수가 해요. LLM은 숫자를 만들지 않아요.

## 6. Agent 구조
```
사용자 질문
  └─ ① 의도 파악: 지역, 시간대, 관심 공백, 결과물 형태 → 모호하면 되묻기
  └─ ② 데이터 점검: 올린 CSV를 열어 어떤 데이터인지 판별, 컬럼 대응, 좌표계 확인
  └─ ③ 전처리: 제주 필터, TM 좌표 변환, 결측과 중복 처리
  └─ ④ 공백 계산: 정류장 반경 집계, 점수
  └─ ⑤ 자기 점검과 분기 (아래 표)
  └─ ⑥ 반출 점검: 10 미만 값 가리기, 역산 가능성 점검
  └─ ⑦ 결과: 우선 10곳 표, 지도 그림, 근거 카드, 건의 문장 초안
```

### 판단·자율 수행 범위 (기획서 필수 항목)
| 상황 | Agent가 스스로 하는 일 | 사용자에게 묻는 일 |
|---|---|---|
| 올린 파일 종류가 불분명 | 컬럼 이름과 값으로 판별, 근거 표시 | 판별 신뢰도가 낮을 때 확인 |
| 좌표가 TM(미터 단위) | 자동으로 위경도로 변환, 변환 전후 표본 표시 | 없음 |
| 보안등 자료 없음 | 빛 공백을 "자료 없음"으로 표시하고 나머지로 계산 | 자료가 있으면 올려달라고 안내 |
| 밤 하차가 너무 적어 순위가 불안정 | 시간대를 20~24시로 넓혀 다시 계산, 넓혔다고 알림 | 없음 |
| 상위 10곳이 한 동에 몰림 | 몰림 비율을 알리고 읍면동별 상위도 함께 제시 | 지역 분산 순위를 원하는지 |
| 결과에 10 미만 값 | 해당 값을 "10 미만"으로 바꿈 | 없음 |
| 질문 지역에 정류장이 없음 | 가장 가까운 정류장 3곳으로 대체 제안 | 대체해도 되는지 |

- Agent가 하지 않는 일: 범죄 발생 예측, 특정 개인이나 장소를 "위험"으로 단정, 원자료 행을 LLM에 보내기.

## 7. 모델과 도구
- **LLM:** Claude API(도구 호출)로 ①, ②, ⑤의 판단과 ⑦의 문장 작성을 맡겨요. 키가 없거나 외부 접속이 막히면 **규칙 기반 계획기**로 같은 도구를 같은 순서로 실행해요.
- **LLM에 보내는 것:** 컬럼 이름, 행 수, 집계 결과, 점수표만 보내요. 원자료 행은 보내지 않아요.
- **도구 목록:** `list_files`, `profile_csv`, `identify_dataset`, `convert_coords`, `filter_region`, `compute_gaps`, `rerun_with_options`, `export_check`, `render_map`, `make_cards`
- **실행 환경:** Python 3.10 이상 표준 라이브러리만 사용해요. 로컬 서버(127.0.0.1)와 브라우저 화면으로 동작해요. 지도는 외부 지도 서비스 없이 SVG로 그려요.
- **외부 접속:** `api.anthropic.com` 하나만 써요. 기획서에 명시해요.

## 8. 남은 확인 사항
1. 50m 격자코드의 좌표 대응표 제공 여부 (게시판 질문)
2. 보안등 위치 자료 확보 가능 여부 (게시판 질문)
3. 공개 CCTV·비상벨 CSV를 제출물에 포함해도 되는지 (게시판 질문)
4. 3-04의 하차 기록 비율: 제주 버스는 하차 태그가 의무가 아니라서, 하차가 적게 잡힐 수 있어요. 승차 기록으로 보정하는 옵션을 둬요.
